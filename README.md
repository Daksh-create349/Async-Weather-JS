# Weather App

The Weather App is a simple web application that displays weather information for a selected city. The user selects a city from a dropdown list and clicks a button to view the weather details.

---

## 📌 Project Objective

To demonstrate:
- User input using dropdown menus
- Button click handling in JavaScript
- Dynamic content display using the DOM

---

## 🛠 Technologies Used

- HTML
- CSS
- JavaScript

---

## ⚙️ How It Works

- The user selects a city from the dropdown list.
- On clicking the **Get Weather** button:
  - JavaScript processes the selected city
  - Weather information is displayed on the screen
- If no city is selected, an appropriate message is shown.

---

## 💻 How to Run the Project

1. Download or clone the project files
2. Open `index.html` in any modern web browser
3. Select a city and click **Get Weather**

---

## 🧠 Key Concepts Used

- DOM selection using `getElementById()`
- Event handling with `addEventListener()`
- Conditional statements (`if-else`)
- Dynamic text update using `textContent`

---

## 🎯 Learning Outcome

After completing this project, you will understand:
- How dropdown inputs work in JavaScript
- How to respond to user actions
- How to build basic interactive applications
